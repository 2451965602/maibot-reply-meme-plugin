# MaiBot 回复配图插件

从 `aigengtu.com` 的公开图库按关键词、情绪和角色筛选表情包，并在**工具调用所在的聊天流**发送。

## 功能与使用边界

- 仅访问 `aigengtu.com` 与 `img.aigengtu.com` 的 HTTPS 资源，手动校验每一次跳转。
- 限制索引和图片大小、图片格式与尺寸；不把图库元数据当成指令。
- 采用两阶段流程：`find_meme` 最多返回四张候选图作为 `content_items` 供模型观察，不会发送；模型选定后调用 `send_meme(selection_id, choice)`，只发送一张。
- 需要具备视觉能力的模型才能观察候选图并正确选择；若模型不能处理图片，不应调用 `send_meme` 猜选。
- `mode=reply` 遵循单会话冷却；`mode=request` 只应在用户明确点图时使用。
- 只经 MaiBot `send.image` 投递给当前 `stream_id`，没有任意收件人参数；候选绑定原聊天流并在 5 分钟后过期；发送未确认时不会重试。
- 候选最多缓存 16 组、每组最多 4 张，单张候选图严格限制为 1 MiB；下载仍保留 12 MiB 原始文件上限以及格式、尺寸校验。插件卸载时清空候选缓存。
- 每个 `stream_id` 的「已发过去重摘要」和「主动配图时间」只存在内存里，并共用同一份回收记录：空闲超过 1 小时（3600 秒，不低于冷却时间上限）的聊天流在下次调用时惰性丢弃；聊天流条目最多 512 个，超出时淘汰最久未写入的流。单个流的去重摘要最多保留最近 80 条，因此去重不是永久记忆，也不会随 `stream_id` 数量无限增长。达到上限后最久未写入的流可能重新参与候选，冷却也可能提前复位。
- `find_meme` 和 `send_meme` 注册为核心工具，回复模型可直接调用，不依赖工具搜索发现；必须先观察 `find_meme` 返回的图片，再调用 `send_meme`。

## 安装与配置

将仓库目录复制到 MaiBot 的 `plugins/` 目录后，重启 MaiBot 主程序。插件运行器会依据 `_manifest.json` 安装 `aiohttp` 依赖。

插件配置分为“插件设置”和“回复配图设置”两组。可通过 `enabled` 启停工具、通过 `auto_reply` 控制轻松对话中的主动配图，并调整同一聊天流的冷却时间。`default_count` 与 `max_count` 为兼容保留项；当前候选流程最多提供四张供视觉模型判断，最终仅发送一张。
